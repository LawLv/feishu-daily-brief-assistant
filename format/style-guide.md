# 固定版式规范

## 视觉

| 用途 | 取值 |
| --- | --- |
| 页面背景 | `#f2efe7`，淡暖灰 |
| 模块背景 | `#faf7ef`，淡米色 |
| 标题区背景 | `#e9eee5` |
| 主文字 / 正文 | `#263a41` / `#31474d` |
| 次要文字 / 边框 | `#627379` / `#dcded6` |
| 蓝 / 绿 / 橙 / 紫 | `#397ac2` / `#29967b` / `#d69742` / `#9371c7` |

模块标题和编号采用模块色的浅色混合，不使用大片高饱和背景。

## 字体和层次

- 主字体：LXGW WenKai Screen v1.530，CSS别名`Brief WenKai`；回退为Microsoft YaHei UI、微软雅黑和sans-serif。
- 正文：18px，字重400，行高1.85。
- 主标题：29—40px，字重700；日期范围25—36px，字重700，置于h1内。
- 模块标题29px、条目标题21px、模块结论19px、一句话概括18px，均加粗。
- 条目前有编号色块；来源链接15px、图片说明14px。
- 使用屏幕阅读版原字体，保持略带书写感和足够厚实的笔画，避免过细字体。

## 布局和图片

- >1300px：三列；821—1300px：两列；≤820px：一列。
- 固定六模块，全内容平铺；不用折叠、标签页或交互隐藏正文。
- 图片按原比例完整显示，max-width:100%，max-height:400px，不裁切关键内容。
- 图片后附可见事实说明、日期与来源。

## 模板维护

`report-reading.css`是可维护样式源；`report-template.ts`的`reportCSS`为同版样式副本。修改后需要同步两者，再更新实际发布环境。占位样例不构成任何真实技术事实。

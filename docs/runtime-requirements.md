# 运行能力与配置要求

## 必须实际验证的能力

- 账号有权读取目标会话、话题回复、邮件正文和必要文档。
- 工具能分页并覆盖统计范围，能在需要时补读上下文。
- 云端任务有独立的数据连接和持久化保存路径，不依赖本机缓存。
- 发布器能保存本期数据、更新latest并读回核对。
- 图片资源的实际字节可以取得，才能做自动原图配图；仅有image_key不足以展示。

工具名feishu_report_format / feishu_publish_report / feishu_read_report是约定的接口名称；在其他环境可使用等效实现，不能假定某个默认连接天然包含它们。

## 私有配置项

| 变量 | 用途 |
| --- | --- |
| `FEISHU_CONNECTION` | 已验证的飞书只读连接 |
| `REPORT_SITE_ID` | 既有报告网站/发布器标识 |
| `REPORT_BASE_URL` | 实际报告网站的HTTPS地址 |
| `TIMEZONE` | 统计与调度的时区，如Europe/Berlin |
| 运行日与时间 | 按使用者设置，在工作前留足生成时间 |
| 模型和推理强度 | 本次流程采用GPT-6.1 Sol / high，可按实际可用配置调整 |

凭据由授权服务管理；不写入本仓库、提示词示例、报告或日志。需要跨设备运行时，应分别核实数据授权、写入权限与任务执行位置，不能只凭任务名称判断。

## 失败处理

- 连接失效：明确通知需要重新连接，不冒充完成读取。
- 权限或数据缺口：报告实际覆盖范围，区别“没有更新”和“未能读取”。
- 图片不可读：保留文字结论与来源，说明限制。
- 发布失败：保留上一份成功报告，不能将其称为本期结果。
- 首次运行：手动验证一次相同流程，再检查首批定时运行结果。

相关产品说明可参考[OpenAI定时任务文档](https://learn.chatgpt.com/docs/automations)；具体环境以实际工具和任务设置为准。
